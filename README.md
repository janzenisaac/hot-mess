# HOT//MESS

[Play in your browser](https://janzenisaac.github.io/hot-mess/)

A ridiculous endless survival game. No login, installation, or AI service.

**Computer:** WASD / arrows to move. **Phone:** drag to move. Your gun fires automatically.

Pick HOT or NOT when interrupted. Both can boost or nerf you. Three hits end the run.
One personal best is saved on this browser. Enter or tap to retry.

This repository contains only the public static website, not backend code or credentials.
